# Outputs

Esta carpeta contiene los resultados generados por `src/thumbs_generator.py`.

Cada localidad se guarda en una carpeta independiente y los resultados se organizan por año:

```text
outputs/
└── <LOCALIDAD>/
    ├── building_index.csv
    ├── building_index.gpkg
    └── <AÑO>/
        └── *.png
```
